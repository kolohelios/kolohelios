# `uptime`

External synthetic monitoring for the portfolio, via [Better
Stack](https://betterstack.com) (Better Uptime), managed with Terraform.
Sub-issue #196 of the portfolio (#186, slice #2): a belt to `shaka domain
check`'s suspenders — `domain check` catches configuration drift from the
inside, these probes catch reachability failures from outside Cloudflare.

## Layout

- `terraform/main.tf` — the `betteruptime` provider and two monitors:
  - **`apex_http`** — a `status` monitor on `https://kolohelios.com`
    (2XX over HTTPS), the outside-in reachability check.
  - **`apex_dns`** — a `dns` monitor that asks a public resolver
    (`var.dns_resolver`) to resolve `var.apex_domain`, so NS/zone
    delegation failures surface independently of the HTTP path.
- `terraform/variables.tf` — apex URL/domain, resolver, and check
  interval (defaults to the Better Stack free-tier interval).
- `terraform/outputs.tf` — `monitor_ids`, for cross-referencing in the
  dashboard.

Both monitors email on a new incident (`email = true`); the alert lands
on the Better Stack account owner, which is enough for a personal
portfolio.

## Building

```
nix develop . --command just validate
```

runs the same `tofu validate` / `nix fmt --check` / whitespace steps CI
runs for this project (via `shaka preflight`).

## Provisioning

### Bootstrap (one-time, manual)

The monitoring vendor's own API token can't be Terraform-managed without
a chicken-and-egg, so it's minted by hand:

1. Sign up for Better Stack (free tier) and create a team for
   `kolohelios`.
2. In the dashboard, go to **Settings → API tokens** and mint a Uptime
   API token.
3. Store it in 1Password as item **`Better Stack Uptime API Token`**
   (field `password`) in the kolohelios vault — the reference in
   `.env.example` resolves to
   `op://vedq2v6cmtkglnonkenrjneepa/Better Stack Uptime API Token/password`.

### Apply

```
cp .env.example .env       # `.env` is gitignored
op run --env-file=.env -- just plan
op run --env-file=.env -- just apply
```

`.env.example` documents the full shape; the `betteruptime` provider
auto-detects `BETTERUPTIME_API_TOKEN` from the environment.

### Remote state

State is held in the shared `kolohelios` `Linode` Object Storage bucket
under `tfstate/uptime/terraform.tfstate`. The backend is declared by
`terraform/backend.tf`, generated by
`shaka object-store tfstate emit --module infra/uptime/terraform` (re-run
if the namespace changes; do not edit by hand).

To run `tofu` against the remote backend, export the bucket-scoped S3
credentials minted by `shaka object-store init` (the `op run` step in the
preceding section resolves them from 1Password):

```
export AWS_ACCESS_KEY_ID=<from 1Password / GH secret TFSTATE_ACCESS_KEY>
export AWS_SECRET_ACCESS_KEY=<from 1Password / GH secret TFSTATE_SECRET_KEY>
```

If migrating existing local state into the remote backend, run
`shaka object-store tfstate migrate --module infra/uptime/terraform`
once after the credentials are exported.

   Better Stack dashboard.

## Notes

- **Check interval.** `var.check_frequency` defaults to the Better Stack
  free-tier interval (180 seconds, or 3 minutes). #196 nominally asked
  for 5 minutes; this matches the free tier rather than forcing a value
  it won't accept.
- **Out of scope** (#196): multi-region probing, a public status page,
  and complex alerting/escalation.
