# `cloudflare-portfolio`

Cloudflare Pages project that serves the static portfolio at
`https://kolohelios.com`. Slice #2 of #186 — a placeholder static origin
that proves the edge path end-to-end before slice #3 (#189) swaps in the
Rust + Axum app.

## Layout

- `terraform/main.tf` — Cloudflare provider and the
  `cloudflare_pages_project` resource (Direct Upload — no git
  integration).
- `terraform/outputs.tf` — `pages_subdomain` is the stable contract the
  apex CNAME in `infra/cloudflare-dns` consumes.
- `site/` — static assets (`index.html`) uploaded by `wrangler pages
  deploy`. The deploy step is decoupled from `tofu apply`: TF owns the
  project shell, content is pushed separately.

## Provisioning

The Pages-management token consumed here is provisioned by
`infra/cloudflare-tokens` (see #289) and lands in 1Password at
`op://vedq2v6cmtkglnonkenrjneepa/Cloudflare Pages Management Token/password`.
Apply that project before this one.

After `cloudflare-tokens` has been applied:

```
cp .env.example .env       # `.env` is gitignored
op run --env-file=.env -- just plan
op run --env-file=.env -- just apply
```

`.env.example` documents the full shape; the Cloudflare provider
auto-detects `CLOUDFLARE_API_TOKEN` from the environment.

## Deploying content

Direct Upload doesn't run a build pipeline — `wrangler` uploads the
contents of `site/` and Cloudflare flips the new deployment to
production:

```
op run --env-file=.env -- wrangler pages deploy site --project-name=kolohelios-portfolio --branch=main
```

Until the apex CNAME (in `infra/cloudflare-dns`) propagates,
verify against the Pages default subdomain:

```
curl -I https://kolohelios-portfolio.pages.dev
```

After the apex CNAME is live and `TTL` has settled:

```
curl -I https://kolohelios.com                    # 200
curl -I https://kolohelios.com -H 'cache-control:' # cf-cache-status: HIT on the second hit
```

## Remote state

State is held in the shared `kolohelios` `Linode` Object Storage bucket
under `tfstate/cloudflare-portfolio/terraform.tfstate`. The backend is
declared by `terraform/backend.tf`, generated by
`shaka object-store tfstate emit --module
infra/cloudflare-portfolio/terraform` (re-run if the namespace changes;
do not edit by hand).

S3-compatible credentials for the bucket come from the same
`shaka object-store init` flow the sibling `cloudflare-*` projects use;
references live in `.env.example`.

## Slice #3 hand-off

Slice #3 (#189) replaces the static origin with a Rust + Axum app
deployed elsewhere (`Fly` / `Hetzner` / `workers-rs` — decided when
